<objective>
## Goal
Implement `DataFetcher` (JUCE Thread polling NOAA SWPC) and `SpaceWeatherState` (atomic struct with null handling and last-valid cache), plus unit tests covering the parser with fixture JSONs.

## Purpose
DataFetcher is the data input layer — everything downstream (SynthParamMapper, VisualRenderer) depends on a correctly structured SpaceWeatherState. Parser correctness with nulls and storm data must be verified before wiring into the audio pipeline.

- `src/DataFetcher.h` / `src/DataFetcher.cpp` — Thread subclass; parses NOAA JSON; atomic state update; last-valid fallback
- `tests/Main.cpp` — JUCE UnitTestRunner entry point
- `tests/DataFetcherTests.cpp` — parser unit tests (fixture-based, no network)
- `tests/fixtures/*.json` — quiet day, storm day, all-null fixtures for wind and Kp

    **src/DataFetcher.h:**
    ```cpp
    #pragma once
    #include <juce_core/juce_core.h>
    #include "SpaceWeatherState.h"

    class DataFetcher : public juce::Thread {
    public:
        DataFetcher();
        ~DataFetcher() override;

        SpaceWeatherState getState() const;
        void setPollIntervalMs(int ms);  // for testing

        // Exposed for unit testing — parse fixture strings directly
        bool parseSolarWindJson(const juce::String& json, SpaceWeatherState& out) const;
        bool parseKpJson(const juce::String& json, SpaceWeatherState& out) const;

    private:
        void run() override;
        void fetchAndUpdateState();

        mutable juce::CriticalSection lock;
        SpaceWeatherState state;

        // last-valid cache — retained when fields are null
        float lastVelocity =  450.0f;
        float lastDensity  =    5.0f;
        float lastBz       =    0.0f;
        float lastKp       =    0.0f;

        int pollIntervalMs = 60000;

        static constexpr auto kWindUrl = "https://services.swpc.noaa.gov/json/rtsw/rtsw_wind_1m.json";
        static constexpr auto kKpUrl   = "https://services.swpc.noaa.gov/json/planetary_k_index_1m.json";
    };
    ```

    **src/DataFetcher.cpp:**

    Constructor: call `startThread()` immediately.

    Destructor: call `stopThread(2000)`.

    `getState()`: lock, copy, return.

    `setPollIntervalMs`: set `pollIntervalMs`.

    `run()` loop:
    ```cpp
    void DataFetcher::run() {
        while (!threadShouldExit()) {
            fetchAndUpdateState();
            wait(pollIntervalMs);  // juce::Thread::wait — interruptible
        }
    }
    ```

    `fetchAndUpdateState()`:
    ```cpp
    void DataFetcher::fetchAndUpdateState() {
        SpaceWeatherState next;
        {
            juce::ScopedLock sl(lock);
            next = state;  // copy current (preserves last-valid fields)
        }

        // Fetch solar wind
        auto windJson = juce::URL(kWindUrl).readEntireTextStream();
        if (!windJson.isEmpty())
            parseSolarWindJson(windJson, next);

        // Fetch Kp
        auto kpJson = juce::URL(kKpUrl).readEntireTextStream();
        if (!kpJson.isEmpty())
            parseKpJson(kpJson, next);

        // Determine source
        if (windJson.isEmpty() && kpJson.isEmpty())
            next.source = SpaceWeatherState::Source::cached;
        else
            next.source = SpaceWeatherState::Source::live;

        // Increment age if using cached data
        if (next.source == SpaceWeatherState::Source::cached)
            next.data_age_s += pollIntervalMs / 1000;
        else
            next.data_age_s = 0;

        {
            juce::ScopedLock sl(lock);
            state = next;
        }
    }
    ```

    `parseSolarWindJson(json, out)`:
    - Parse with `juce::JSON::parse(json)` → `juce::var`
    - Check isArray(), get element [0]
    - Extract `speed` (→ velocity), `density`, `bz_gsm`
    - For each field: if isDouble() or isInt(), update both out field AND lastVelocity/lastDensity/lastBz
    - If field is null/undefined: out field = last valid value (no update to lastValid)
    - Set out.timestamp from `time_tag` or `propagated_time_tag`
    - Return true if array was non-empty and parseable

    `parseKpJson(json, out)`:
    - Same pattern
    - Extract `estimated_kp`
    - If null: out.kp = lastKp; if valid: out.kp = value; lastKp = value
    - Return true if parseable
