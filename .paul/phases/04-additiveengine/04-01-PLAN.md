<objective>
## Goal
Implement Interpolator (per-field slew on SynthParams at control rate) and AdditiveEngine (two-layer additive oscillator bank consuming smoothed SynthParams), wired into PluginProcessor.processBlock(). Verify CPU ≤5% at 32 partials/layer.

## Purpose
AdditiveEngine is the first step that produces actual audio. Without it, SynthParamMapper output is never heard. The Interpolator ensures the drone evolves continuously between DataFetcher updates rather than stepping — essential to the aesthetic goal.

## Output
- `src/Interpolator.h` / `.cpp` — per-field slew on SynthParams, control-rate update, configurable glide time
- `src/OscillatorBank.h` / `.cpp` — N sinusoidal partials, harmonic series, amplitude taper, stereo pan
- `src/AdditiveEngine.h` / `.cpp` — two OscillatorBanks (L1+L2), owns Interpolator, renders stereo audio
- `src/PluginProcessor.h` / `.cpp` — updated: AdditiveEngine member, setSynthParams(), processBlock() renders drone
- `CMakeLists.txt` — new sources added
</objective>

    **src/Interpolator.h:**
    ```cpp
    #pragma once
    #include "SynthParams.h"

    class Interpolator {
    public:
        void prepare(double sampleRate, int controlRateHz = 100);
        void setTarget(const SynthParams& target);
        void setGlideTimeSecs(float seconds);
        SynthParams getSmoothed();   // call at control rate
        void reset(const SynthParams& value);

    private:
        // Per-field slew state
        struct SlewState {
            float current = 0.0f;
            float target  = 0.0f;
        };

        // Map each SynthParams float field to a SlewState
        SlewState l1_hz, l1_timbre, l1_amp;
        SlewState l2_hz, l2_density, l2_bright, l2_amp;
        SlewState stereo_w;
        int l1_harmonic_count_target = 2;   // integer — snaps, no slew

        float alpha = 0.0f;  // per-step decay coefficient: alpha = 1 - exp(-1/(glide*controlRate))
        float glideTimeSecs = 2.0f;
        int   controlRateHz = 100;

        void updateAlpha();
        static float slew(SlewState& s, float a);
    };
    ```

    **src/Interpolator.cpp:**

    `prepare(sampleRate, controlRateHz)`: store controlRateHz, call updateAlpha().

    `setGlideTimeSecs(s)`: store glideTimeSecs, call updateAlpha().

    `updateAlpha()`:
    ```cpp
    // alpha is the per-step coefficient for exponential approach
    // At each control step: current += alpha * (target - current)
    // Reaches 99% in glideTimeSecs
    alpha = 1.0f - std::exp(-4.6f / (glideTimeSecs * controlRateHz));
    // (ln(100) ≈ 4.6 → 99% convergence in glideTimeSecs)
    ```

    `setTarget(SynthParams t)`: update all target fields.

    `getSmoothed()`:
    ```cpp
    SynthParams out;
    out.l1_fundamental_hz   = slew(l1_hz,     alpha);
    out.l1_timbre           = slew(l1_timbre,  alpha);
    out.l1_amplitude        = slew(l1_amp,     alpha);
    out.l2_fundamental_hz   = slew(l2_hz,      alpha);
    out.l2_harmonic_density = slew(l2_density, alpha);
    out.l2_brightness       = slew(l2_bright,  alpha);
    out.l2_amplitude        = slew(l2_amp,     alpha);
    out.stereo_width        = slew(stereo_w,   alpha);
    out.l1_harmonic_count   = l1_harmonic_count_target;  // integer snap
    return out;
    ```

    `reset(v)`: set all current and target fields to v's values immediately (no slew).

    `slew(SlewState& s, float a)`:
    ```cpp
    s.current += a * (s.target - s.current);
    return s.current;
    ```

    **src/OscillatorBank.h:**
    ```cpp
    #pragma once
    #include <vector>
    #include "SynthParams.h"

    class OscillatorBank {
    public:
        void prepare(double sampleRate, int maxPartials = 24);

        // Update oscillator frequencies and amplitudes from SynthParams.
        // layer: 0 = L1 (solar wind), 1 = L2 (Kp)
        void applyParams(const SynthParams& p, int layer, float layerGain);

        // Render 'numSamples' into left/right output buffers (ADDS to existing content)
        void render(float* left, float* right, int numSamples);

    private:
        struct Partial {
            double phase    = 0.0;
            double phaseInc = 0.0;  // radians per sample
            float  ampLeft  = 0.0f;
            float  ampRight = 0.0f;
        };

        std::vector<Partial> partials;
        double sampleRate = 44100.0;
        int activePartials = 0;
    };
    ```

    **src/OscillatorBank.cpp:**

    `prepare(sr, maxPartials)`: resize partials vector, store sampleRate.

    `applyParams(SynthParams p, int layer, float layerGain)`:
    - For layer 0 (L1): fundamental = p.l1_fundamental_hz, count = p.l1_harmonic_count
      - Spectral tilt: partial[i].ampLeft/Right = base_amp * (1/(i+1)) * timbre_envelope
      - timbre_envelope: when l1_timbre=0, pure harmonic taper (1/(i+1)); when l1_timbre=1, add inharmonic detuning (partial[i].phaseInc *= 1 + timbre * 0.003 * i)
      - l1_amplitude already in SynthParams — use as overall L1 gain
    - For layer 2 (L2): fundamental = p.l2_fundamental_hz
      - Partials driven by l2_harmonic_density: activePartials = 2 + (int)(22 * l2_harmonic_density)
      - amplitude per partial = p.l2_amplitude * (1/(i+1)) * brightness_factor
      - brightness_factor: higher l2_brightness → more energy in upper partials (brightness_factor = 1 + i * l2_brightness * 0.5)... but clamp total amp
    - Pan each layer: layerGain and stereo_width determine left/right split
      - L1 panned slightly left: leftGain = 0.5 + stereoWidth * 0.3; rightGain = 0.5 - stereoWidth * 0.3
      - L2 panned slightly right: opposite

    `render(left, right, numSamples)`:
    ```cpp
    for (int i = 0; i < activePartials; ++i) {
        auto& p = partials[i];
        for (int n = 0; n < numSamples; ++n) {
            float s = std::sin(p.phase) * p.ampLeft;  // reuse for simplicity
            left[n]  += (float)(std::sin(p.phase)) * p.ampLeft;
            right[n] += (float)(std::sin(p.phase)) * p.ampRight;
            p.phase  += p.phaseInc;
            if (p.phase > juce::MathConstants<double>::twoPi)
                p.phase -= juce::MathConstants<double>::twoPi;
        }
    }
    ```
    Note: using `juce::MathConstants` is fine here — OscillatorBank is compiled as part of SolarDrone with JUCE available.

    **src/AdditiveEngine.h:**
    ```cpp
    #pragma once
    #include <juce_audio_basics/juce_audio_basics.h>
    #include "SynthParams.h"
    #include "UserParams.h"
    #include "Interpolator.h"
    #include "OscillatorBank.h"

    class AdditiveEngine {
    public:
        void prepare(double sampleRate, int samplesPerBlock);
        void setSynthParams(const SynthParams& target);
        void setUserParams(const UserParams& params);
        void processBlock(juce::AudioBuffer<float>& buffer);

    private:
        void updateControlRate();  // called every controlPeriod samples

        OscillatorBank l1Bank, l2Bank;
        Interpolator   interp;
        UserParams     userParams;

        SynthParams smoothed;
        int controlCounter   = 0;
        int controlPeriod    = 441;  // ~100Hz at 44.1kHz
        double sampleRate    = 44100.0;

        bool prepared = false;
    };
    ```

    **src/AdditiveEngine.cpp:**

    `prepare(sr, spb)`:
    - l1Bank.prepare(sr, 24); l2Bank.prepare(sr, 24)
    - interp.prepare(sr, 100)
    - controlPeriod = (int)(sr / 100.0)
    - sampleRate = sr; prepared = true

    `setSynthParams(target)`: interp.setTarget(target)

    `setUserParams(params)`:
    - userParams = params
    - interp.setGlideTimeSecs(params.dynamics_range > 0 ? userParams.layer_balance * 300 : 120)
    - Actually: glide time is a UserParam — add `float glide_time_secs = 120.0f` to UserParams
    - Call interp.setGlideTimeSecs(params.glide_time_secs)

    **Add `glide_time_secs` to UserParams.h** (same file, add field):
    ```cpp
    float glide_time_secs = 120.0f;  // 30-300s configurable
    ```

    `processBlock(buffer)`:
    ```cpp
    buffer.clear();
    if (!prepared) return;

    auto* left  = buffer.getWritePointer(0);
    auto* right = buffer.getWritePointer(1);
    int remaining = buffer.getNumSamples();
    int offset = 0;

    while (remaining > 0) {
        if (controlCounter <= 0) {
            updateControlRate();
            controlCounter = controlPeriod;
        }
        int chunk = std::min(remaining, controlCounter);
        l1Bank.render(left + offset, right + offset, chunk);
        l2Bank.render(left + offset, right + offset, chunk);
        offset += chunk;
        remaining -= chunk;
        controlCounter -= chunk;
    }
    ```

    `updateControlRate()`:
    ```cpp
    smoothed = interp.getSmoothed();
    // Constant-power layer balance crossfade
    const float angle = userParams.layer_balance * juce::MathConstants<float>::halfPi;
    float l1Gain = std::cos(angle);
    float l2Gain = std::sin(angle);
    l1Bank.applyParams(smoothed, 0, l1Gain);
    l2Bank.applyParams(smoothed, 1, l2Gain);
    ```
