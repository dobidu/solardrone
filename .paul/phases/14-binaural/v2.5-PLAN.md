<objective>
## Goal
Add per-layer spatial positioning (azimuth + elevation) to L1, L2, L3. Implement ILD (Interaural Level Difference) panning. Add SpatialDisplay component: oval head top-down view with 3 draggable colored dots (L1=blue, L2=Kp-colored, L3=orange). Place in right panel.

## Binaural model
ILD only (no ITD delay in v2.5). Constant-power panning law:
  angle = ((az/90.0) * π/4) + π/4   → [0, π/2]
  gainL = cos(angle)
  gainR = sin(angle)
Elevation modulates l1_timbre slightly: adds 0.3 * (elevation/45) to timbre for upper sounds.

    ```cpp
    static std::pair<float,float> computeSpatialGains(float azimuthDeg, float elevationDeg) {
        // ILD: constant-power panning law
        const float az  = std::max(-90.f, std::min(90.f, azimuthDeg));
        const float t   = (az / 90.0f + 1.0f) * juce::MathConstants<float>::halfPi / 2.0f;
        float gL = std::cos(t);
        float gR = std::sin(t);
        // Elevation: slight level reduction for extreme angles
        const float el   = std::max(-45.f, std::min(45.f, elevationDeg));
        const float elScale = 1.0f - std::abs(el) / 45.0f * 0.15f;  // max 15% reduction
        return {gL * elScale, gR * elScale};
    }
    ```

    ```cpp
    auto [l3L, l3R] = computeSpatialGains(userParams.l3_azimuth, userParams.l3_elevation);

    const float ang = userParams.layer_balance * juce::MathConstants<float>::halfPi;
    ```
