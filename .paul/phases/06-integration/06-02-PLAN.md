<objective>
## Goal
Add APVTS (AudioProcessorValueTreeState) to PluginProcessor exposing all user parameters for DAW automation. Add a minimal controls panel in PluginEditor (bottom strip, 80px). Wire all sliders/toggles to APVTS attachments.

## Purpose
SolarDrone's core value requires runtime control — glide time, layer balance, visual blends, on/off. Without APVTS, the plugin has no automatable parameters and no user controls beyond what's hardcoded. This plan makes the plugin a full first-class JUCE plugin with DAW-automatable state.

    **processBlock()** — read params and update engine:
    ```cpp
    void SolarDroneAudioProcessor::processBlock(
        juce::AudioBuffer<float>& buffer, juce::MidiBuffer&)
    {
        // Read APVTS params into userParams
        userParams.dynamics_range          = *apvts.getRawParameterValue("dynamics_range");
        userParams.layer_balance           = *apvts.getRawParameterValue("layer_balance");
        userParams.stereo_spread           = *apvts.getRawParameterValue("stereo_spread");
        userParams.glide_time_secs         = *apvts.getRawParameterValue("glide_time");
        userParams.visual_lissajous        = *apvts.getRawParameterValue("vis_lissajous");
        userParams.visual_particles        = *apvts.getRawParameterValue("vis_particles");
        userParams.visual_spectral         = *apvts.getRawParameterValue("vis_spectral");
        userParams.l1_l2_interval_semitones =
            (int)*apvts.getRawParameterValue("interval");
        userParams.harmony_mode = (*apvts.getRawParameterValue("harmony_mode") < 0.5f)
            ? UserParams::HarmonyMode::just
            : UserParams::HarmonyMode::equalTemperament;

        engine.setUserParams(userParams);

        // Poll DataFetcher — only re-map when new data arrives
        auto state = fetcher.getState();
        if (state.timestamp != lastTimestamp) {
            lastTimestamp = state.timestamp;
            engine.setSynthParams(SynthParamMapper::map(state, userParams));
        }

        // Drone on/off + volume
        const bool droneOn = *apvts.getRawParameterValue("drone_on") > 0.5f;
        const float volume = *apvts.getRawParameterValue("volume");

        if (droneOn) {
            engine.processBlock(buffer);
            buffer.applyGain(volume);
        } else {
            buffer.clear();
        }
    }
    ```

    **getStateInformation / setStateInformation** — APVTS handles XML:
    ```cpp
    void SolarDroneAudioProcessor::getStateInformation(juce::MemoryBlock& destData) {
        auto state = apvts.copyState();
        std::unique_ptr<juce::XmlElement> xml(state.createXml());
        copyXmlToBinary(*xml, destData);
    }

    void SolarDroneAudioProcessor::setStateInformation(const void* data, int sizeInBytes) {
        std::unique_ptr<juce::XmlElement> xml(getXmlFromBinary(data, sizeInBytes));
        if (xml && xml->hasTagName(apvts.state.getType()))
            apvts.replaceState(juce::ValueTree::fromXml(*xml));
    }
    ```

    void SolarDroneAudioProcessorEditor::resized() {
        auto bounds = getLocalBounds();
        // Controls panel: bottom 80px
        auto controlsArea = bounds.removeFromBottom(80);
        // Visual fills remaining top area
        visualRenderer.setBounds(bounds);

        // Controls layout: 2 rows of controls
        const int lh = 12;   // label height
        const int sh = 20;   // slider height
        const int row1y = controlsArea.getY() + 4;
        const int row2y = row1y + lh + sh + 4;

        // Row 1: Vol | Glide | Dyn | Bal | Sprd | ON
        const int totalSliders1 = 5;
        const int btnW = 40;
        const int slW1 = (controlsArea.getWidth() - btnW - 10) / totalSliders1;

        int x = controlsArea.getX() + 4;
        auto placeSlider = [&](juce::Slider& s, juce::Label& l, int w) {
            l.setBounds(x, row1y, w, lh);
            s.setBounds(x, row1y + lh, w, sh);
            x += w + 2;
        };
        placeSlider(slVolume,   lblVolume,   slW1);
        placeSlider(slGlide,    lblGlide,    slW1);
        placeSlider(slDynamics, lblDynamics, slW1);
        placeSlider(slBalance,  lblBalance,  slW1);
        placeSlider(slSpread,   lblSpread,   slW1);
        btnDroneOn.setBounds(x, row1y + lh, btnW, sh);

        // Row 2: Harmony | Ivl | Liss | Part | Spec
        x = controlsArea.getX() + 4;
        const int comboW = 70;
        cmbHarmony.setBounds(x, row2y + lh, comboW, sh);
        juce::Label harmLabel;  // static — hack: draw label via paint instead
