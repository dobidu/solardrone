# v2.8 Resonator Engine — Overview

## Milestone target
Three parallel resonator layers driven by live solar data, adding timbral depth impossible to achieve with additive synthesis alone.

## Architecture

```
processBlock():
  drone = AdditiveEngine (existing)
  modal_out = ModalBank.process(drone)          // parallel
  fdn_out   = FDN.process(drone)                // parallel
  string_out = SympatheticStrings.process(drone) // parallel
  output = drone*dry + modal_out*wet_m + fdn_out*wet_f + string_out*wet_s
  → Chopper → EQ → volume
```

## Three resonators

### Modal Bank (32 biquads)
- 32 StateVariableTPTFilter in bandpass mode
- Frequencies: f_k = l1_fundamental_hz × k^(1 + inharmonicity)
  → pure harmonic (k=1,2,3...) at inharmonicity=0
  → stretched/inharmonic at inharmonicity>0
- Q = π × f_k × decay_time
- **Solar driver:** Kp → mode count (4–32), wind velocity → decay time

### FDN 8-tap (Hadamard)
- 8 delay lines, coprime lengths, normalized Hadamard matrix
- Each delay: absorption lowpass filter for T60 per frequency band
- **Solar driver:** Dst index → T60 multiplier (deep storm = long cavernous tail)
- **Solar driver:** dynamic pressure → absorption LPF cutoff

### Sympathetic Strings (12 comb filters)
- 12 comb filters, each = DelayLine + single-pole lowpass feedback
- Tuned to: l1_fundamental_hz × scale_degree[k] (k=1..12)
- Feedback near 0.995 (base), reduced by proton flux
- **Solar driver:** proton flux ≥10 MeV → damping + noise injection
