
    **DataFetcher.h** — add:
    ```cpp
    bool parseDstJson(const juce::String& json, SpaceWeatherState& out);
    bool parseProtonFluxJson(const juce::String& json, SpaceWeatherState& out);
    // private:
    float lastTemperature    = 80000.f;
    float lastDst            = 0.f;
    float lastProtonFlux     = 0.3f;
    static constexpr const char* kDstUrl =
        "https://services.swpc.noaa.gov/products/kyoto-dst.json";
    static constexpr const char* kProtonUrl =
        "https://services.swpc.noaa.gov/json/goes/primary/integral-protons-1-day.json";
    ```

    **DataFetcher.cpp — parseSolarWindJson()**: add temperature parsing:
    ```cpp
    extract("temperature", out.temperature, lastTemperature);
    ```
    (uses existing extract lambda — temperature is 4th column in the wind JSON)

    **DataFetcher.cpp — fetchAndUpdateState()**: add two new fetches:
    ```cpp
    auto dstJson    = juce::URL(kDstUrl).readEntireTextStream();
    auto protonJson = juce::URL(kProtonUrl).readEntireTextStream();
    if (!dstJson.isEmpty()    && parseDstJson(dstJson, next))
        lastDst = next.dst_index;
    else { next.dst_index = lastDst; }
    if (!protonJson.isEmpty() && parseProtonFluxJson(protonJson, next))
        lastProtonFlux = next.proton_flux_10mev;
    else { next.proton_flux_10mev = lastProtonFlux; }
    ```

    Note: Dst is hourly — frequent polling (60s) is fine; NOAA caches responses.

    **parseDstJson(json, out)**:
    - Parse JSON array, most recent entry first
    - Extract `dst` field (float, nT)
    - Field name in Kyoto feed: `"dst"` value is integer
    - Fallback to lastDst on null/missing

    **parseProtonFluxJson(json, out)**:
    - Parse JSON array, find most recent entry with `energy` == "≥10 MeV"
    - Extract `flux` field (float, pfu)
    - If null or 0, use lastProtonFlux
    - Note: NOAA field might be "integral_flux" or "flux" — check fixture

    Fixture for proton flux (from NOAA format):
    ```json
    [{"time_tag":"...","satellite":18,"energy":">=10 MeV","flux":0.5},
     {"time_tag":"...","satellite":18,"energy":">=50 MeV","flux":0.02}]
    ```
    Filter: `energy` starts with ">=10" or contains "10 MeV".
