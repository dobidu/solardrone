    `updateFromSolarData(sw, l1Hz)`:
    Called from message thread (timerCallback). Solar mappings:

    ```cpp
    // Modal: velocity → decay (fast wind = bright, shorter decay)
    const float normVel = std::max(0.f, std::min(1.f, (sw.velocity - 300.f) / 500.f));
    modalBank.setDecaySeconds(modalDecayUser * (2.f - normVel * 1.5f)); // 0.5s–2s

    // Modal: Kp → mode count (storm = dense inharmonic modes)
    const int modeCount = 4 + (int)(28.f * (sw.kp / 9.f));
    modalBank.setModeCount(std::max(4, std::min(32, modeCount)));

    // Modal: Kp → inharmonicity
    modalBank.setInharmonicity(sw.kp >= 6.f ? (sw.kp - 6.f) / 3.f * 0.4f : 0.f);

    // Modal: fundamental tracks L1 pitch
    modalBank.setFundamental(l1Hz);

    // FDN: Dst → T60 (deep storm = very long tail)
    const float dstNorm = std::max(0.f, std::min(1.f, -sw.dst_index / 200.f));
    fdn.setT60(fdnT60User * (0.3f + dstNorm * 7.7f));  // 0.3× to 8× multiplier

    // FDN: dynamic pressure → absorption cutoff
    const float pressure = 1.67e-6f * sw.density * sw.velocity * sw.velocity;  // nPa
    const float pressNorm = std::max(0.f, std::min(1.f, (pressure - 1.f) / 49.f));
    fdn.setAbsorptionCutoff(12000.f - pressNorm * 8000.f);  // 12kHz quiet → 4kHz high pressure

    // Strings: proton flux → damping + noise
    const float fluxLog = std::max(0.f, std::log10(std::max(0.3f, sw.proton_flux_10mev)) - std::log10(0.3f));
    const float protonNorm = std::min(1.f, fluxLog / 4.f);  // 0 at background, 1 at X10
    strings.setDamping(protonNorm * 0.8f);
    strings.setNoiseLevel(protonNorm > 0.3f ? (protonNorm - 0.3f) / 0.7f : 0.f);

    // Strings: fundamental tracks L1
    strings.setFundamental(l1Hz);
    ```

    `process(buffer)`:
    ```cpp
    void ResonatorEngine::process(juce::AudioBuffer<float>& buffer) {
        const int n = buffer.getNumSamples();
        const int ch = buffer.getNumChannels();

        // Copy dry to all three temp buffers
        for (int c = 0; c < ch; ++c) {
            modalBuf.copyFrom( c, 0, buffer, c, 0, n);
            fdnBuf.copyFrom(   c, 0, buffer, c, 0, n);
            stringBuf.copyFrom(c, 0, buffer, c, 0, n);
        }

        // Process each resonator on its temp copy
        modalBank.process(modalBuf);
        fdn.process(fdnBuf);
        strings.process(stringBuf);

        // Mix back: result = modal + fdn + strings (already wet-mixed inside each)
        // But we need dry + wet sum, so each process() applies its own wet/dry
        // Just output the sum of all three processed buffers (each is dry+wet internally)
        // BUT: that would add 3× dry signal! Need to subtract 2× dry.
        // Simpler: each resonator outputs wet-only (not wet+dry); dry handled here.
        //
        // Fix: resonator process() outputs WET-ONLY signal (not dry+wet).
        // Then here: output = dry + modal_wet + fdn_wet + string_wet
        //
        // Note: ModalBank/FDN/SympatheticStrings need to be modified to output
        //       wet-only (without adding dry back). Add a flag or separate method.
        // For v2.8.3: use processWetOnly() variant.

        for (int c = 0; c < ch; ++c) {
            auto* out = buffer.getWritePointer(c);
            const auto* m = modalBuf.getReadPointer(c);
            const auto* f = fdnBuf.getReadPointer(c);
            const auto* s = stringBuf.getReadPointer(c);
            for (int i = 0; i < n; ++i)
                out[i] = out[i] + m[i] + f[i] + s[i];  // dry + 3× wet signals
        }
    }
    ```

    Implementation note: the resonator classes' `process()` methods must add ONLY the wet signal to the buffer (not mix dry back in). Revise Task 1 of v2.8.2 accordingly: in each `process()`, the output buffer contains `wet * resonated_signal` only, without the dry signal. The dry mix happens in ResonatorEngine.

    Alternatively: call `setWet(1.0)` and handle dry in ResonatorEngine. See boundary note.
