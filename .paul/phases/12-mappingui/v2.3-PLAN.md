    ```cpp
    const float t = params.map_bz_thresh;   // e.g. -10
    if (bz >= 0.0f) {
        out.l1_timbre = 0.0f;
    } else if (bz > t) {
        out.l1_timbre = (bz - 0.0f) / (t - 0.0f) * 0.3f;  // 0 at bz=0, 0.3 at bz=t
    } else {
        const float x = clamp((t - bz) / 7.0f, 0.0f, 1.0f);  // 0 at bz=t, 1 at bz=t-7
        out.l1_timbre = 0.3f + 0.7f * x;
    }
    ```

    **src/MappingCurveDisplay.cpp:**

    `setParams(vlo, vhi, bzt, kpd)`: store, repaint.
    `setLive(v)`: store, repaint.
    `setKp(k)`: currentKp = k; repaint.

    `paint(g)`:
    - Draw 4 mini-curves side by side (or 2×2)
    - Each 78×40px + 12px label = 52px total height
    - Total display: 2 rows × 2 cols → ~160×106px

    Layout (2×2):
    ```
    [vel→pitch]   [Bz→timbre]
    [Kp→amp]      [Kp→density]
    ```

    `drawCurve(g, area, label, fn, liveInput)`:
    - Fill dark background
    - Border: accent withAlpha(0.2)
    - Draw curve: sample fn() at 40 points across area width
    - Map y: 0=bottom, 1=top
    - Draw as juce::Path, stroke 1.5px, accent color
    - Live indicator: vertical line at x=liveInput*w, accent withAlpha(0.6)
    - Label at bottom: 8pt

    Curve functions:
    - vel→pitch: `fn(x) = log(velLo + x*(velHi-velLo)) / log(velHi)` (normalized log)
      Actually: map input x (0-1 = 300-800 km/s) → output y (0-1 = velLo-velHi Hz normalized)
      `y = (log(velLo * pow(velHi/velLo, x)) - log(velLo)) / (log(velHi) - log(velLo))`
      Simplified: `y = x` (the log-scale maps linearly in normalized space — just show as diagonal line with endpoints labeled)
      Actually: `y = (pow(velHi/velLo, x) * velLo - velLo) / (velHi - velLo)` — this is the actual normalized output.

    - Bz→timbre: input x (0-1 = 0 to -30 nT, left=0=positive, right=1=-30 nT)
      `bz = 0 - x*30;` then apply existing formula with bzThresh
      Output = l1_timbre normalized [0,1]

    - Kp→amplitude: `fn(x) = 0.1 + 0.9*(x*9)/9` = `0.1 + 0.9*x` (linear)

    - Kp→density: step activation at `kpDens/9`, then quadratic rise
      `if (x*9 < kpDens) y=0; else y = pow((x*9-kpDens)/(9-kpDens), 2)`

    Live input values:
    - vel→pitch: `(live.velocity - 300) / 500` (clamped 0-1)
    - Bz→timbre: `(-live.bz) / 30` (clamped 0-1, since bz is negative)
    - Kp→amp: `live.kp / 9`
    - Kp→density: `live.kp / 9`
