<objective>
## Goal
Implement VisualRenderer — a JUCE Component with three composited visual layers (Lissajous curves, particle field, spectral morphing), each driven by smoothed SynthParams and blended via three weights in UserParams. Renders at ~30fps on the message thread without blocking the audio thread.

## Visual metaphor decisions (chosen by user before plan creation)
- **Layer 1 — Lissajous**: animated parametric curve X=sin(ω₁t), Y=sin(ω₂t+δ). Ratio ω₁/ω₂ from L1/L2 fundamentals. Phase δ drifts with time. Color from l1_timbre (blue=calm, red=storm).
- **Layer 2 — Particles**: ~50 particles driven by l1_amplitude (speed) and l1_timbre (turbulence). Hue from l2_brightness (violet→orange). l2_harmonic_density → particle density.
- **Layer 3 — Spectral**: vertical bars at harmonic positions. l1_harmonic_count bars, heights tapered 1/(i+1), l1_timbre warps positions. L2 layer adds a brightness-colored overlay.
- **Blend**: UserParams.visual_lissajous, visual_particles, visual_spectral (0–1 each). All default 0.7.

## Purpose
Without the VisualRenderer, SolarDrone has no visual output — it's just an audio plugin. The visual layer makes it suitable for installation contexts and makes the space weather data tangible beyond sound.

## Output
- `src/VisualRenderer.h` / `.cpp` — Component + Timer, three layers, lock-free SynthParams handoff
- `src/UserParams.h` — 3 blend weight fields added
- `src/PluginEditor.h` / `.cpp` — VisualRenderer embedded in editor, fills available space
- `CMakeLists.txt` — VisualRenderer.cpp added

    **src/VisualRenderer.h:**
    ```cpp
    #pragma once
    #include <juce_gui_basics/juce_gui_basics.h>
    #include <vector>
    #include "SynthParams.h"
    #include "UserParams.h"

    class VisualRenderer : public juce::Component, public juce::Timer {
    public:
        VisualRenderer();
        ~VisualRenderer() override;

        // Thread-safe: may be called from any thread
        void setSynthParams(const SynthParams& p, const UserParams& u);

        void paint(juce::Graphics&) override;
        void resized() override {}
        void timerCallback() override;

    private:
        // ── Lissajous layer ───────────────────────────────────────────────
        void drawLissajous(juce::Graphics&, const SynthParams&, float blend);
        double lissPhase = 0.0;   // slowly drifting phase offset between X and Y

        // ── Particle layer ─────────────────────────────────────────────────
        struct Particle {
            float x = 0.5f, y = 0.5f;  // normalized 0-1
            float vx = 0.0f, vy = 0.0f;
            float life = 1.0f;          // 0=dead, 1=just born
            float hue  = 0.6f;          // 0.6=blue-violet, 0.1=orange
            float size = 3.0f;
        };
        void drawParticles(juce::Graphics&, const SynthParams&, float blend);
        void updateParticles(const SynthParams&, float dt);
        std::vector<Particle> particles;
        float spawnAccum = 0.0f;

        // ── Spectral layer ─────────────────────────────────────────────────
        void drawSpectral(juce::Graphics&, const SynthParams&, float blend);

        // ── Thread-safe SynthParams handoff ────────────────────────────────
        juce::CriticalSection paramsLock;
        SynthParams displayParams;
        UserParams  displayUserParams;

        // Frame timing
        juce::int64 lastFrameMs = 0;
    };
    ```

    **src/VisualRenderer.cpp:**

    Constructor: `startTimerHz(30)`. Initialize 50 particles with random positions.

    Destructor: `stopTimer()`.

    `setSynthParams(p, u)` — called from audio thread or anywhere:
    ```cpp
    juce::ScopedLock sl(paramsLock);
    displayParams     = p;
    displayUserParams = u;
    ```

    `timerCallback()`:
    ```cpp
    SynthParams p; UserParams u;
    {
        juce::ScopedLock sl(paramsLock);
        p = displayParams;
        u = displayUserParams;
    }
    auto nowMs = juce::Time::currentTimeMillis();
    float dt = lastFrameMs > 0 ? (float)(nowMs - lastFrameMs) / 1000.0f : 0.033f;
    lastFrameMs = nowMs;
    dt = std::min(dt, 0.1f);  // cap delta to avoid spiral on slow frames

    updateParticles(p, dt);
    lissPhase += (double)p.l1_timbre * 0.3 * dt + 0.05 * dt;  // drift phase
    repaint();
    ```

    `paint(Graphics& g)`:
    ```cpp
    g.fillAll(juce::Colours::black);
    SynthParams p; UserParams u;
    {
        juce::ScopedLock sl(paramsLock);
        p = displayParams;
        u = displayUserParams;
    }
    if (u.visual_spectral   > 0.01f) drawSpectral(g, p, u.visual_spectral);
    if (u.visual_particles  > 0.01f) drawParticles(g, p, u.visual_particles);
    if (u.visual_lissajous  > 0.01f) drawLissajous(g, p, u.visual_lissajous);
    ```
    *(spectral first = background, particles middle, Lissajous on top)*

    `drawLissajous(g, p, blend)`:
    - N = 512 points of parametric curve
    - ratio = p.l1_fundamental_hz / p.l2_fundamental_hz (clamped to [0.5, 4])
    - For t in [0, 2π * precision_periods]: x=sin(t), y=sin(ratio*t + lissPhase)
    - Map to component rect (with margin)
    - Color: hue interpolated from l1_timbre (0→blue 0.6, 1→red 0.0). Alpha = blend * 0.8
    - Draw as juce::Path (moveTo first point, lineTo rest), strokePath with 1.5f width
    - Line thickness increases with l1_amplitude

    `updateParticles(p, dt)`:
    - Base speed from p.l1_amplitude (0.05–0.3 normalized/s)
    - Turbulence from p.l1_timbre (adds random velocity kicks)
    - Hue from p.l2_brightness (0=blue/violet, 1=orange)
    - Target particle count: 5 + (int)(45 * p.l2_harmonic_density)
    - spawnAccum += targetCount * dt; while spawnAccum >= 1.0 { spawn(); spawnAccum -= 1.0 }
    - Each frame: position += velocity * dt; life -= dt / lifetime; remove dead
    - Lifetime = 3 + p.l2_amplitude * 4 seconds

    `drawParticles(g, p, blend)`:
    - For each live particle: draw filled circle at (x*w, y*h) with size*blend, alpha = life*blend

    `drawSpectral(g, p, blend)`:
    - Draw l1_harmonic_count vertical bars across bottom third of component
    - Bar i: x position = log-scaled at fundamental * (i+1), clamped to [0, w]
    - Height = (1/(i+1)) * p.l1_amplitude * h * 0.3 * blend
    - Color: l1_timbre interpolates blue→orange; warped x by timbre * 5px * i
    - L2 overlay: draw l2_harmonic_density * 22 + 2 thin lines with l2_brightness color, semi-transparent

    Note: `smoothed` is updated in `updateControlRate()` on the audio thread. Reading it from the editor thread without a lock is technically a data race. Fix: protect `smoothed` with the same lock pattern as VisualRenderer's paramsLock. For simplicity in this phase: AdditiveEngine stores a copy accessible via a CriticalSection.

    **Simplest approach**: editor's VisualRenderer gets updated by PluginProcessor calling `visualRenderer.setSynthParams(smoothed, userParams)` from processBlock(). But PluginProcessor doesn't own the editor.

    **Correct approach**: VisualRenderer polls via a Timer callback, calling `processorRef.getCurrentSynthParams()`. AdditiveEngine protects `smoothed` with a SpinLock or returns a copy under a CriticalSection.

    Implement this in AdditiveEngine:
    - Add `juce::CriticalSection smoothedLock` to AdditiveEngine private
    - In `updateControlRate()`: `{ juce::ScopedLock sl(smoothedLock); smoothed = interp.getSmoothed(); }` then use local copy
    - In `getSmoothedParams()`: `juce::ScopedLock sl(smoothedLock); return smoothed;`

    **Update VisualRenderer::timerCallback()** to also call:

    ```cpp
    // After computing dt and updating particles, poll processor if available

    ```

    Simplest: pass `SolarDroneAudioProcessor*` to VisualRenderer constructor. In timerCallback(), call `processorRef->getCurrentSynthParams()` and update displayParams under the lock.

    Update VisualRenderer constructor signature:

    Store as `SolarDroneAudioProcessor* processor = nullptr;`
