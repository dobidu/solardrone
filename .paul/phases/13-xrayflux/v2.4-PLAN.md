<objective>
## Goal
Add NOAA X-ray flux data (solar flares) to DataFetcher. When flux crosses M-class threshold, trigger a burst 3rd harmonic layer (L3) in AdditiveEngine with ADSR envelope. Visual: SunDisc pulses and VisualRenderer shows a brief flash on X-class events.

## Data source
`https://services.swpc.noaa.gov/json/goes/secondary/xrays-1-minute.json`
Field used: `flux` (W/m²). Flare classes: B≥1e-7, C≥1e-6, M≥1e-5, X≥1e-4.

## Effect: L3 burst layer
- Frequency: l1_fundamental_hz × 1.5 (perfect 5th of L1 — cuts through mix)
- Amplitude: 0 at quiet, proportional to log-normalized flux above M threshold
- ADSR: attack 2s, sustain while flux above threshold, decay 20s
- 8 partials max (sparse, bright timbre)
- Controlled by APVTS param `flare_sensitivity` (0-1, default 0.7)

## Output
- `SpaceWeatherState`: add `x_ray_flux` (float W/m²) and `flare_class` (enum B/C/M/X/None)
- `DataFetcher`: parse xrays-1-minute.json; second HTTP fetch in run() loop
- `SynthParams`: add `l3_amplitude`, `l3_fundamental_hz`, `l3_active` (bool)
- `AdditiveEngine`: 3rd OscillatorBank + BurstEnvelope (attack/decay)
- `VisualRenderer`: flash effect + flare class badge
- `PluginProcessor`: `flare_sensitivity` APVTS param
</objective>
