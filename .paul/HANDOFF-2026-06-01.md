## Architecture Snapshot

```
DataFetcher (5 NOAA feeds, 60s) → SpaceWeatherState
  → SynthParamMapper → Interpolator → AdditiveEngine (L1 solar wind + L2 Kp)
  → BeatRepeater (reverse/stutter/pan) → Chopper (atk/rel/phase)
  → ResonatorEngine (modal/FDN/strings, all default OFF)
  → OutputEQ → audio
VisualRenderer (3D Lissajous + 200+ particles + spectral, toggleable)
ResonatorPanel: 3 resonator cols + SolarTerminal (10fps) + EQ + live data strip
OSCMIDIBridge: timerCallback (message thread ONLY, never audio thread)
ScopedNoDenormals: processBlock + ResonatorEngine::process (CRITICAL for Windows)
```
