## Architecture Snapshot

```
DataFetcher (5 NOAA feeds, 60s) → SpaceWeatherState
  → SynthParamMapper → Interpolator → AdditiveEngine (L1+L2)
  → BeatRepeater (reverse/stutter/pan) → Chopper (atk/rel/phase)
  → ResonatorEngine (modal/FDN/strings, all off by default)
  → OutputEQ → audio
VisualRenderer (3D Lissajous + 200+ particles + spectral, toggleable)
ResonatorPanel: 3 resonator cols + SolarTerminal + EQ + live data strip
OSCMIDIBridge: timerCallback (message thread ONLY)
ScopedNoDenormals: processBlock + ResonatorEngine::process
```
